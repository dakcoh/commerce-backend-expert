# 0.3.1 검증 기록

2026-10-24, Windows·Node.js 24.22.1·npm 11.19.1·Codex CLI 0.153.2에서 확인했다. 현재 릴리스 후보의 검증이며 태그 생성·공개 릴리스 완료를 뜻하지 않는다.

## 지식 검토

`webhook-handling`은 [토스페이먼츠 v2 웹훅 문서](https://docs.tosspayments.com/guides/v2/webhook)의 응답 코드·제한시간·재전송 범위를 확인했다. 특정 PG의 조건을 모든 PG에 확대하지 않으며, 짧은 동기 처리 허용과 긴 후처리 분리는 프로젝트의 설계 판단이다.

`concurrency-distributed`는 [Redisson Lock 문서](https://redisson.pro/docs/data-and-services/locks-and-synchronizers/#lock)의 획득 결과·lease·watchdog·소유 스레드 해제를 확인했다. 관련 재고 체크리스트·결제 원장 지침·리뷰 스킬과의 설명도 비교했다. 주문자·결제자·수령자 구분은 `commerce-customer-identity`의 적용 조건과 함께 확인했다.

두 규칙의 AI 문서 검토자·날짜·범위를 기록했다. 실제 DB·PG·Redis 및 운영 계약 검증은 없으므로 `needs-review`는 19개 그대로다. AI 문서 검토를 사람의 승인이나 운영 안전성 인증으로 간주하지 않는다.

## Codex 훅

실제 배포 구성의 두 훅을 격리 프로필에 설치한 뒤 `/hooks`에서 검토·신뢰했다. 신뢰 우회 옵션이나 진단용 기본 훅은 사용하지 않았다. 이후 같은 프로필의 app-server로 다음 절차를 수행했다.

1. `hooks/list`에서 두 훅의 `trusted` 상태와 후보 0.3.1 설치 경로를 확인한다.
2. `thread/start` → `turn/start`로 시작·명령·일반 프롬프트를 전달한다. 클라이언트의 `hook/completed`와 반환 문맥을 확인한다.
3. 프로세스를 종료·재시작하고 같은 대화를 `thread/resume`으로 재개한다.
4. `thread/compact/start`로 실제 수동 압축을 실행하고 다음 요청에서 SessionStart 문맥을 확인한다.
5. 프로젝트·세션을 바꿔 상태 격리를 확인한다.

모델 요청은 localhost의 결정적인 Responses 응답 대역으로 보냈다. 대역은 고정 답변만 반환하고 명령이나 도구를 실행하지 않는다. 훅 호출과 요청 문맥 전달은 실제 Codex의 동작이지만, AI의 스킬 선택·추론 품질을 검증한 시험은 아니다. 인증 정보 복사·원격 모델 호출은 없었다.

| 확인 항목 | 확인 결과 |
|---|---|
| 시작 | ON과 설치된 두 스킬의 경로 |
| off → status | OFF 유지 |
| 일반 프롬프트·부정문 | 추가 문맥 없음, 상태 변경 없음 |
| 프로세스 재시작·재개 | 같은 프로젝트·세션은 OFF 유지 |
| 실제 수동 압축 | 다음 요청에 OFF 문맥 전달 |
| on | ON과 스킬 경로 복원 |
| 다른 프로젝트·세션 | 기본 ON, 원 프로젝트의 OFF 유지 |

## 설치·갱신

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm test
node scripts/smoke-plugin.js /absolute/path/to/codex v0.3.0
```

Git이 가리키는 실제 v0.3.0 소스를 별도 폴더에 추출해 설치한 뒤, 같은 `commerce-backend-expert@commerce-context-mcp`로 후보 0.3.1을 설치한다. 런타임 파일 89개의 목록·내용 일치, 같은 버전 재설치, 별도 시험 버전 갱신, 제거·캐시 삭제를 확인한다. 평소 사용자 프로필과 기존 태그를 변경하지 않는다.

위 검사와 로컬 자동 테스트 37개가 통과했다. `skills@1.7.4`의 로컬 프로젝트 설치도 대표 단독·리뷰 단독·동시 설치로 각각 실행해, 선택한 스킬만 설치되는지와 LICENSE·참조·규칙 70개의 유효성을 확인했다. 설치에는 `--agent codex --copy --yes --skill <선택한 스킬>`을 사용했으며 모델과 세션 훅은 실행하지 않았다.

## 남은 범위

후보 커밋의 원격 CI·공개 배포는 별도 완료 확인이 필요하다. Claude의 실제 재개·압축, Cursor·OpenClaw 실제 실행, 자동 압축·다른 Codex 버전, 실제 DB·PG·Redis, 반복·미사용 대조군 평가는 미검증이다.

English: The candidate was checked on Windows with Node 24.22.1 and Codex CLI 0.153.2. Hook trust was reviewed in an isolated profile; actual client lifecycle calls used deterministic local model responses. This verifies hook execution and context delivery, not model quality. The two changed high-risk rules received scoped AI document reviews and retain needs-review. Other clients, live systems, remote candidate CI, and publication require separate evidence.
