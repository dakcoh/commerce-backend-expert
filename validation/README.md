# 검증 기록

이 폴더는 플러그인의 설치·훅·모델 적용·업무 규칙을 **어떤 조건에서 시험했고 무엇이 남았는지** 보관한다. 실행용 스킬과 세션 훅은 `skills/`와 `hooks/`에 있으며, 배포 파일을 복사하는 설치 검사는 이 폴더를 포함하지 않는다. 이 폴더 자체가 AI 문맥에 자동 주입되지는 않는다. 저장소 전체를 설치한 경우 파일이 함께 있어도 모델이 명시적으로 읽는 경우에만 그 내용이 문맥에 들어간다.

모델 효과·토큰·시간의 비교 실험은 [benchmarks/](../benchmarks/README.md)에 있다. 임시 프로필·다운로드한 실행 파일·모델 가중치·상세 로그는 Git에서 제외한 `output/`에 보관한다. 실제 고객정보·비밀키를 공개 검증 기록에 넣지 않는다.

최신 상태를 판단할 때는 날짜뿐 아니라 소스 해시·클라이언트/모델 버전·입력·실제 실행 여부를 함께 확인한다. 과거 파일을 최신 성공 결과로 덮어쓰거나, 오프라인 검사 통과를 실제 모델·사업자 환경의 통과로 바꾸지 않는다.

보고서와 JSON의 소스 커밋·작업 트리 상태·`committed`/`pushed` 값은 실험을 기록한 시점의 정보다. 자료를 나중에 커밋·공개해도 당시 측정값과 출처를 소급 변경하지 않는다. 기본 검사에서는 `tests/`·`benchmarks/`·`validation/` 아래의 Markdown 링크를 자동 탐색해 검사한다.

2026-10-27 사용자 요청으로 [#23](https://github.com/dakcoh/commerce-backend-expert/issues/23)은 결함 이슈에서 제외해 `not planned`로 종료했다. 실제 사업 환경 확인은 각 도입 환경의 검증 조건으로 남으며 `needs-review` 규칙의 승인을 의미하지 않는다. 이전 보고서에 있는 #23 대기 표시는 당시 상태다.

같은 날 [#22](https://github.com/dakcoh/commerce-backend-expert/issues/22)는 파일 작업 종료 조건과 CSS 최소 편집으로 범위를 정리해 수정·회귀 후 종료했다. [최종 4작업 회귀와 앞선 실패 후보](results/2026-10-27-openclaw-fix.json)를 보존한다. 완료 범위는 기록한 Qwen 설정의 실제 파일 편집이며, 이전의 읽기 전용 전체 HTML 응답 생성·모든 모델의 자동 선택과 업무 추론까지 통과했다는 뜻은 아니다.
